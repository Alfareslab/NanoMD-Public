مشروع NanoMD هو تطبيق ويب خفيف وسريع جداً، مصمم لكتابة وعرض نصوص الـ Markdown بشكل لحظي (Real-time). يهدف التطبيق لتبسيط عملية كتابة التقارير، المقالات، والمراجعات التقنية بدون الحاجة لبرامج معقدة. يتميز التطبيق بتركيزه التام على السرعة، البساطة، وخصوصية المستخدم. يعتمد على React 18 + Vite لتجربة استخدام فائقة السرعة، ويستخدم Tailwind CSS + Manus UI Style لواجهة حديثة ونظيفة. الواجهة الخلفية تعمل على Cloudflare Workers لمعالجة طلبات المشاركة بسرعة البرق حول العالم.

## اختبار 24: قائمة تعريفات (بصيغة عريضة)

**المصطلح الأول: RTL**
هو اتجاه الكتابة من اليمين إلى اليسار (Right-to-Left) المستخدم في اللغة العربية.

**المصطلح الثاني: BiDi**
هو خوارزمية Unicode Bidirectional Algorithm التي تحدد اتجاه عرض النصوص المختلطة.

**المصطلح الثالث: `unicode-bidi`**
خاصية CSS تتحكم في سلوك النص ثنائي الاتجاه داخل العناصر.

## اختبار 25: الحالة الأصلية — Bold + أقواس + شرطة (البرزنتيشن)

**NanoMD** هو تطبيق ويب خفيف وسريع جداً، مصمم لكتابة وعرض نصوص الـ Markdown بشكل لحظي (Real-time). يهدف التطبيق لتبسيط عملية كتابة التقارير، المقالات، والمراجعات التقنية بدون الحاجة لبرامج معقدة. يتميز التطبيق بتركيزه التام على السرعة، البساطة، وخصوصية المستخدم.

## اختبار 26: Bold في بداية فقرة مع خلط كثيف

**React 18** هو الإطار المستخدم في بناء NanoMD ويعمل مع Vite (v5.0) لتوفير تجربة تطوير سريعة. يدعم التطبيق ميزات مثل Hot-Module-Replacement (HMR) وأيضاً Server-Side Rendering (SSR) في المستقبل.

**Cloudflare Workers** تُستخدم كواجهة خلفية (Back-end) لمعالجة طلبات المشاركة عبر API بسرعة فائقة حول العالم. البيانات تُخزّن في Cloudflare KV (Key-Value Store) وتُحذف تلقائياً بعد 30 يوماً.
