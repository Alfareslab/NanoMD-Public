# 🗺️ UI Viewport Lab — NanoMD Interface Preview
> الإصدار: 1.6.1
> التاريخ: 2026-04-24
> الحالة: قيد التنفيذ

## الهدف
إنشاء ملف HTML مستقل يفتح في المتصفح لمحاكاة واجهة NanoMD الحالية داخل مقاسات Desktop / Tablet / Mobile، بهدف مراجعة ترتيب أزرار الهيدر والموبايل قبل تعديل كود التطبيق الأساسي.

## المتطلبات
- الملف يفتح مباشرة في المتصفح بدون تشغيل Dev Server.
- يعرض التطبيق الحقيقي من نسخة `dist/` داخل `iframe`.
- يوفر أزرار تغيير المقاس بين Desktop وTablet وMobile.
- يوفر وضعين أساسيين:
  - قبل وجود محتوى: Empty State.
  - بعد وجود محتوى: Sample Markdown Content عبر URL hash.
- لا يغير كود التطبيق الأساسي.
- لا يضيف مكتبات جديدة.
- يكون مناسب للمراجعة البصرية السريعة للأزرار والمساحات.

## ملاحظات
- الملف لا يشغّل Vite ولا Worker ولا API.
- المشاركة والترجمة قد لا تعملان داخل المعمل إذا كانت تعتمد على `/api/...`، لأن الهدف هنا مراجعة الواجهة وترتيب الأزرار فقط.
- يجب تشغيل `npm run build` عند الحاجة لتحديث `dist/` قبل استخدام المعمل.
- لو `dist/index.html` لم يعمل بشكل صحيح من `file://` بسبب مسارات assets، سيتم تعديل طريقة تحميل الـ iframe داخل المعمل بدون تغيير كود التطبيق الأساسي.
