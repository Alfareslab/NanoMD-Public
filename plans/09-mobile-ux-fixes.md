> **الإصدار:** 1.4.1

## 🎯 الهدف العام
حل مشكلات واجهة المستخدم المكتشفة في الإصدار 1.4.0، وتحديداً: فصل ظهور أزرار الترجمة عن السكرول، إنشاء شريط إجراءات سفلي (Bottom Action Bar) في الموبايل لمنع تداخل الأزرار مع النصوص، وتوفير وصول سريع للعمليات الأساسية (تبديل العرض، لصق، مشاركة) في شاشات الموبايل.

- [x] **بوابة عدم التجريد:** سنستخدم CSS و Tailwind الموجودين حالياً لعمل الـ Bottom Bar.
- [x] **بوابة الوضوح:** المتطلبات الأربعة تم الموافقة عليها بشكل صريح ومحدد.
