# 📋 بروتوكول وضع المراجعة (Review Mode Rules)
>
> **الإصدار:** 1.0.0
> **آخر تحديث:** 2026-02-24

---

> **متى تقرأ هذا الملف؟**
> عندما يطلب المطور مراجعة قرارات، أو عندما تحتاج موافقته على بنود متعددة.

---

## القاعدة الذهبية

> **بدل ما تسأل المطور أسئلة متفرقة في الشات — اكتب تقرير مراجعة منظم يلصقه في NanoMD ويرد عليك فيه.**

---

## 1. متى تستخدم وضع المراجعة؟

| الحالة | استخدم Review Mode؟ |
|--------|---------------------|
| عندك **3 بنود أو أكثر** محتاج قرار فيهم | ✅ نعم |
| سؤال واحد بسيط | ❌ لا — اسأل في الشات |
| خطة تحتاج موافقة بند بند | ✅ نعم |
| تقرير audit محتاج ردود | ✅ نعم |
| اختيارات تصميم متعددة | ✅ نعم |

---

## 2. صيغة كتابة تقرير المراجعة

> ⚠️ **التزم بهذه الصيغة بالحرف — NanoMD يعتمد عليها للكشف الأوتوماتيكي.**

### الجدول الإلزامي

```markdown
| # | البند | التفاصيل | التوصية | القرار |
|---|-------|----------|--------|--------|
| 1 | [عنوان مختصر] | [شرح تفصيلي] | [توصيتك] | |
| 2 | [عنوان مختصر] | [شرح تفصيلي] | [توصيتك] | |
```

### قواعد الأعمدة

| العمود | الوظيفة | مَن يكتبه؟ | يُنسخ في الرد؟ |
|--------|---------|------------|----------------|
| `#` | رقم البند | 🤖 الوكيل | ✅ نعم |
| `البند` | ملخص مختصر | 🤖 الوكيل | ✅ نعم |
| `التفاصيل` | شرح تفصيلي | 🤖 الوكيل | ❌ لا |
| `التوصية` | رأي الوكيل | 🤖 الوكيل | ❌ لا |
| `القرار` | رد المطور | 👤 المطور | ✅ نعم |

> **النقطة الذكية:** عند النسخ، يتم نسخ `#` + `البند` + `القرار` فقط — بدون الشرح الطويل.

---

## 3. أسماء الأعمدة المعتمدة (Auto-detect)

> NanoMD يكشف Review Mode أوتوماتيكياً لو العمود الأخير اسمه أحد الأسماء التالية **وقيمته فارغة**:

| الاسم (عربي) | الاسم (إنجليزي) |
|-------------|----------------|
| القرار | Decision |
| الرد | Response |
| قرار المطور | Dev Decision |

---

## 4. الأزرار السريعة في NanoMD

عند كشف جدول مراجعة، NanoMD يضيف أزرار لكل صف:

| الزر | الرمز | ماذا يكتب في خلية القرار؟ |
|------|-------|---------------------------|
| موافق | ✅ | `✅ موافق` |
| رفض | ❌ | `❌ رفض` |
| تأجيل | ⏸️ | `⏸️ تأجيل` |

> بعد الضغط على أي زر، يمكن للمطور **إضافة تعليق** بجانب القرار.
>
> مثال: `✅ موافق — بس خلي اللون أغمق`

---

## 5. زر نسخ الردود

| الحالة | شكل الزر |
|--------|----------|
| مفيش أي رد (0/N) | 🔘 رمادي — متعطل |
| بعض الردود (X/N) | 🟠 برتقالي — `⚠️ نسخ الردود (X/N)` |
| كل الردود (N/N) | 🟢 أخضر — `✅ نسخ الردود (N/N)` |

### صيغة النسخ

```
1. NavBar → ✅ موافق
2. Footer → ✅ موافق — بس خلي العنوان بالعربي
3. Colors → ⏸️ تأجيل
4. Icons → ❌ رفض — مش أولوية
```

> يتم نسخ: رقم البند + عنوانه + قرار المطور فقط.

---

## 6. مثال كامل (من الوكيل)

```markdown
# 🔍 مراجعة: تحديثات NavBar

| # | البند | التفاصيل | التوصية | القرار |
|---|-------|----------|--------|--------|
| 1 | إزالة "الخدمات" | الخدمات موجودة في الـ NavBar والمنصة معرفية مش خدمية | إزالة | |
| 2 | إضافة Local Zone | الفوتر عمود واحد ممركز ومحتاج timezone | إضافة | |
| 3 | ألوان CSS Variables | الألوان hardcoded في 3 ملفات | تحويل لمتغيرات | |
```

---

## 7. مثال الرد (من المطور — بعد النسخ)

```
1. إزالة "الخدمات" → ✅ موافق
2. إضافة Local Zone → ✅ موافق — بس خلي العنوان بالعربي
3. ألوان CSS Variables → ⏸️ تأجيل — مش أولوية دلوقتي
```
