# 🍌 NanoMD

**محرر ماركداون عربي سريع، بسيط، وبدون أي تعقيدات.**

تم تصميم **NanoMD** ليكون الأداة الأمثل لقراءة نصوص الماركدوان المنسوخة من أدوات الذكاء الاصطناعي (مثل ChatGPT و Claude) باللغة العربية. بفلسفة "القراءة أولاً"، يوفر لك NanoMD واجهة نظيفة تدعم اللغة العربية (RTL) بشكل أصيل.

---

## ✨ المميزات الأساسية (نسخة MVP 1.0)

1. **لصق ذكي (Smart Paste):** ادخل الموقع واضغط `Ctrl+V` فقط. سيتحول النص فوراً إلى عرض ماركداون منسق ومقروء.
2. **عربي أصيل (Native RTL):** خطوط "Cairo" الجميلة، محاذاة لليمين، وتنسيق مريح للعين العربية، مع بقاء الأكواد البرمجية من اليسار لليمين.
3. **أوضاع العرض المتعددة:**
   - **وضع القراءة:** التركيز الكامل على النص المنسق.
   - **وضع التعديل:** محرر نصوص خام لتعديل الماركداون.
   - **وضع التقسيم (Split):** عرض مزدوج للمحرر والنتيجة معاً.
   - **وضع التركيز (Focus):** إخفاء كافة القوائم للتركيز التام.
4. **تصدير سهل ومتقدم:**
   - نسخ كنص منسق (Rich Text) للقص واللصق في Word/Outlook.
   - نسخ ماركداون أو HTML، مع القدرة على الطباعة المباشرة لملف PDF.
5. **الذاكرة والحفظ (Offline & Persistence):**
   - حفظ تلقائي مستمر.
   - سجل تاريخ للمسودات.
   - يعمل أوفلاين بالكامل (لا يوجد خوادم).

## 🚀 بدء التشغيل والصيانة (Quickstart)

يجب أن يكون لديك `Node.js` و `pnpm` مثبتين على جهازك.

```bash
# تثبيت الاعتمادات
pnpm install

# تشغيل خادم التطوير
pnpm run dev

# بناء النسخة النهائية
pnpm run build
```

## ⌨️ اختصارات لوحة المفاتيح

- `Ctrl + 1` : وضع القراءة (Preview)
- `Ctrl + 2` : وضع التعديل (Editor)
- `Ctrl + 3` : العرض المزدوج (Split)
- `Ctrl + 4` : وضع التركيز (Focus)
- `Ctrl + V` : لصق ماركداون من الحافظة في أي مكان في التطبيق.

## 🛠 التقنيات المستخدمة

- **الواجهة:** React 18 (TypeScript), Vite
- **التنسيق:** Tailwind CSS, PostCSS, خطوط Google (Cairo)
- **المعالجة:** `react-markdown`, `remark-gfm`, `rehype-sanitize`, `rehype-highlight`
- **الأيقونات:** Lucide-React
- **البيانات:** `localStorage` (100% Client-Side)
