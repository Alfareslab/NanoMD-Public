# 🔍 مراجعة: تحسينات واجهة الموبايل النهائية (Mobile UI Polish)

> **السياق:** فحص مشكلة التكبير التلقائي للموبايل، وتكدس الأزرار في الهيدر والشريط السفلي، بناءً على الصورة المرفقة.
> **الوضع:** 🔧 جراحي
> **المرجع:** `plans/09-mobile-ux-fixes.md`
> **الأقسام:** التكبير والأبعاد (1) · الهيدر والشعار (2) · الشريط السفلي (3–4) · ملاحظات إضافية (5)
> **عدد البنود:** 5 بنود في 4 أقسام

---

| # | البند | التوصية | التفاصيل | القرار |
|---|-------|---------|----------|--------|
| | 📌 التكبير والأبعاد | | | |
| 1 | 🔴 مشكلة التكبير التلقائي (Auto-zoom) وتخطي العرض | إضافة `maximum-scale=1` ومنع الـ Overflow | الشاشة تبدأ مكبرة لأن عرض الشريط السفلي أو الهيدر يتجاوز 100vw، مما يجبر المتصفح على عمل Zoom-out لإظهارها. الحل بمنع الـ Overflow وتثبيت الـ Viewport. | |
| | 📌 الهيدر والشعار | | | |
| 2 | 🔴 الشعار يأخذ مساحة ضخمة من الهيدر | تصميم شعار (NMD) مصغر ووضعه بجانب الأزرار | في الموبايل، الشعار يأخذ سطر كامل. سنقلص الشعار لـ 30% (NMD فقط) ونضع أزرار الهيدر في الـ 70% المتبقية في نفس السطر بتوزيع ذكي. | |
| | 📌 الشريط السفلي | | | |
| 3 | 🔴 زري الترجمة يستهلكان مساحة | دمجهم بزر واحد (مطول للتبديل، قصير للترجمة) | كما اقترحت، زر واحد للترجمة. الضغطة الخفيفة تترجم للغة المحددة، والضغطة المطولة (Long Press) تعكس اتجاه الترجمة (عربي ↔ إنجليزي). | |
| 4 | 🟡 نصوص أزرار الترجمة مزدحمة | الاكتفاء بالأيقونة الديناميكية (AR/EN) | النص (عربي / إنجليزي) تحت الأيقونة المكتوب فيها (AR/EN) يسبب زحاماً في الموبايل. الأفضل تنظيفها بصرياً. | |
| | 📌 ملاحظات إضافية (من فحص الصورة) | | | |
| 5 | 🟢 شريط التمرير (Scrollbar) يظهر بشكل مزعج | إخفاء شريط التمرير المرئي في الموبايل | في الموبايل، المستخدم يمرر باللمس، وشريط التمرير الجانبي يأخذ مساحة ويتداخل مع المحتوى. سنخفيه برمجياً مع إبقاء التمرير فعالاً. | |
