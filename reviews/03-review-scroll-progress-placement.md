# 🔍 مراجعة: مكان شريط التقدم (Scroll Progress Indicator)

> **السياق:** شريط التقدم الأفقي يتقاطع مع النصوص حالياً، ونحتاج لتحديد المكان الأفضل له لتجنب التداخل.
> **الوضع:** 🎯 تطويري
> **المرجع:** `plans/07-rtl-fix-and-navigation.md`
> **الأقسام:** خيارات تصميم الشريط (1–3)
> **عدد البنود:** 3 بنود في 1 قسم

---

| # | البند | التوصية | التفاصيل | القرار |
|---|-------|---------|----------|--------|
| | 📌 خيارات تصميم الشريط | | | |
| 1 | 🔴 شريط رأسي بجانب أزرار التنقل | ✅ الموافقة على هذا الخيار | (اقتراحك) شريط رأسي رفيع يمين أو يسار أزرار التنقل، يبدو أنيقاً ويجمع أدوات التنقل في مكان واحد ولن يتقاطع مع أي نص. | ✅ موافق |
| 2 | 🟡 شريط أفقي أعلى الشاشة (Top: 0) | ❌ الرفض لصالح الشريط الرأسي | يلتصق بأعلى النافذة تماماً (فوق الهيدر) مثل شريط تحميل YouTube. لا يتقاطع مع النص ولكنه بعيد عن منطقة المحتوى. | ✅ موافق |
| 3 | 🟢 دائرة تقدم حول زر (أعلى الملف) | ❌ الرفض لتبسيط التصميم | بدلاً من شريط، يكون هناك خط دائري حول زر "أعلى الملف" يمتلئ مع التمرير. فكرة ممتازة لكنها تحتاج لجهد أكبر في الـ CSS وقد تكون غير واضحة. | ✅ موافق |
