# 🔍 مراجعة: قرارات خطة تحسينات NanoMD v1.1.0

> **السياق:** محتاج قرارات تقنية وتصميمية قبل بدء تنفيذ التحسينات الخمسة
> **الوضع:** 🎯 تطويري
> **المرجع:** `plans/01-nanomd-improvements.md`
> **الأقسام:** تحميل Hash (1) · جداول المراجعة (2–5) · رفع الملفات (6–8)
> **عدد البنود:** 8 بنود في 3 أقسام
> **الحالة:** ✅ تمت المراجعة — 2026-04-08

| # | البند ← التوصية | التفاصيل | القرار |
|---|----------------|----------|--------|
| 1 | 🔴 سلوك Hash بعد التحميل ← مسح Hash من URL بعد التحميل | لو المستخدم فتح رابط فيه Hash ثم عمل Refresh — هل يحمّل المحتوى تاني من الـ Hash ولا من الـ localStorage؟ التوصية: نمسح الـ Hash من URL فوراً بعد التحميل عشان الـ Refresh يكون طبيعي ويحمّل الـ draft المحفوظ | ✅ موافق |
| 2 | 🟡 ترتيب أعمدة الصيغة الجديدة ← `# Item Rec Details Decision` | الصيغة الجديدة للجدول هتكون 5 أعمدة بدل 4. الترتيب المقترح حسب ملف التحسينات. NanoMD يدمج Item + Recommendation بـ `←` عند النسخ تلقائياً | ✅ موافق — فصل في العرض + دمج في النسخ مع القرار |
| 3 | 🟡 مسمى عربي لعمود Recommendation ← إضافة `التوصية` لقائمة الكشف | حالياً NanoMD يكشف أعمدة بالعربي والإنجليزي. هل نضيف `التوصية` كمسمى عربي معتمد لعمود Recommendation في الهيدر الجديد؟ | ✅ موافق — عشان لو اضفنا الإنجليزي لاحقاً |
| 4 | 🟡 نمط كشف صف الفاصل ← `#` فاضي + وجود 📌 في البند | صف الفاصل يتكشف لو عمود `#` فاضي وعمود البند فيه emoji 📌. هل ده كافي؟ ولا محتاج علامات إضافية أو بديلة؟ | ✅ موافق |
| 5 | 🟡 ألوان الأقسام والثيمات ← لونين بالتبادل + CSS variables | كل مجموعة بنود بين فاصلين تاخد لون خلفية مختلف. التوصية: لونين خفيفين بالتبادل (زوجي/فردي) باستخدام CSS variables تتناسب مع الثيمات الثلاثة (Noir, Slate, Cream) | ✅ موافق |
| 6 | 🟢 عداد المراجعة والفواصل ← استثناء الفواصل من العداد والنسخ | Progress bar يعد البنود العادية فقط بدون صفوف الفاصل. صفوف الفاصل ما تتنسخش مع الردود | ✅ موافق |
| 7 | 🟢 زر Upload في الموبايل ← Header + EmptyState فقط | هل نضيف زر Upload كمان في MobileNav للموبايل؟ ولا Header (ديسكتوب) + EmptyState (صفحة البداية) كفاية؟ | ✅ موافق |
| 8 | 🟢 أنواع الملفات المسموحة ← `.md` و `.txt` و `.markdown` فقط | هل الأنواع دي كفاية للـ File Picker؟ ولا نضيف أنواع تانية زي `.mdx` أو `.rst`؟ | ✅ موافق |
